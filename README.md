# نور — تطبيق إسلامي 🌙

تطبيق إسلامي بواجهة عربية كاملة (RTL) يعمل في المتصفح وكتطبيق أندرويد.

## 🌐 افتح التطبيق

**https://tahershawki1.github.io/noor/**

## الأقسام

| القسم | الوصف |
|---|---|
| 📖 **القرآن الكريم** | تصفح 114 سورة بخط المصحف (Amiri Quran)، بحث عن السور، تنقل، وتشغيل تلاوة الآيات صوتياً (مشاري العفاسي). |
| 📿 **الأذكار** | أذكار الصباح والمساء وبعد الصلاة والنوم والاستيقاظ وأدعية جامعة (من حصن المسلم)، مع عدّاد تكرار لكل ذكر وسبحة إلكترونية. |
| 🔖 **الإشارات المرجعية** | احفظ أي آية وارجع إليها لاحقاً. تُحفظ محلياً في `localStorage`. |
| 🕌 **مواقيت الصلاة** | حسب موقعك الجغرافي أو باسم المدينة، مع بطاقة الصلاة القادمة وعدّ تنازلي مباشر، والأذان. |

## هيكل المشروع

```
islamic-app/          ← مصدر تطبيق الويب (هو المنشور على GitHub Pages)
  index.html            هيكل الواجهة والأقسام
  styles.css            التصميم (ثيم داكن أخضر/ذهبي)
  app.js                منطق التطبيق كاملاً
  adhkar-data.js        بيانات الأذكار
www/                  ← نسخة من islamic-app يستخدمها Capacitor لبناء الأندرويد
android/              ← مشروع أندرويد (Capacitor)
capacitor.config.json ← إعدادات Capacitor (appId: com.noor.islamicapp)
.github/workflows/    ← نشر تلقائي على GitHub Pages عند كل push
```

## التشغيل محلياً

التطبيق يحتاج خادم ملفات ثابتة (بسبب طلبات الـ API):

```bash
cd islamic-app && python -m http.server 8090
```

ثم افتح <http://localhost:8090>

## بناء تطبيق الأندرويد

`www/` هي نسخة من محتوى `islamic-app/` (بدون الصوتيات). بعد أي تعديل على `islamic-app/`، انسخ الملفات الأربعة إلى `www/` ثم:

```bash
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```

## مصادر البيانات

- نص القرآن — [alquran.cloud](https://alquran.cloud)
- تلاوة الآيات — [everyayah.com](https://everyayah.com) (مشاري راشد العفاسي، 128kbps)
- مواقيت الصلاة — [Aladhan API](https://aladhan.com/prayer-times-api) (طريقة حساب أم القرى)

## ملاحظات

- يتطلب اتصالاً بالإنترنت لتحميل نص القرآن والتلاوة ومواقيت الصلاة. الأذكار والسبحة تعمل بدون إنترنت بعد أول تحميل.
- ملفات الصوت المحلية (`islamic-app/audio/`, ‏222MB) **غير مرفوعة** في هذا الريبو — التطبيق يجلب التلاوة من everyayah.com مباشرة.
- التاريخ الهجري يُعرض تلقائياً، وآخر موقع/مدينة لمواقيت الصلاة يُحفظ ويُسترجع.

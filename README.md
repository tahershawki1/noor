# نور — تطبيق إسلامي 🌙

تطبيق إسلامي بواجهة عربية كاملة (RTL) يعمل في المتصفح وكتطبيق أندرويد.

## 🌐 افتح التطبيق

**https://tahershawki1.github.io/noor/**

## الأقسام

| القسم | الوصف |
|---|---|
| 📖 **القرآن الكريم** | تصفح 114 سورة بخط المصحف (Amiri Quran) مع **فواصل صفحات المصحف** الـ604، بحث ذكي عن السور، **متابعة القراءة من آخر موضع توقفت عنده**، تفسير الميسر، وتشغيل تلاوة الآيات صوتياً (مشاري العفاسي). |
| 📿 **الأذكار** | أذكار الصباح والمساء وبعد الصلاة والنوم والاستيقاظ وأدعية جامعة (من حصن المسلم)، مع عدّاد تكرار لكل ذكر وسبحة إلكترونية. |
| 🔖 **الإشارات المرجعية** | احفظ أي آية وارجع إليها لاحقاً. تُحفظ محلياً في `localStorage`. |
| 🕌 **مواقيت الصلاة** | تُحسب فلكياً على الجهاز من موقعك أو باسم المدينة، مع بطاقة الصلاة القادمة وعدّ تنازلي مباشر، والأذان. |

## 📴 يعمل بالكامل دون إنترنت

نص المصحف، تفسير الميسر، الخطوط، وحساب مواقيت الصلاة — كلها مرفقة داخل التطبيق:

| المورد | الحجم | كان قبلاً |
|---|---|---|
| `data/quran-text.json` | 1.3 م.ب | api.alquran.cloud |
| `data/tafsir-muyassar.json` | 2.7 م.ب | api.alquran.cloud |
| `data/quran-meta.json` | 14 ك.ب | api.alquran.cloud |
| `data/cities.json` | 169 ك.ب | api.aladhan.com |
| `fonts/*.woff2` | 707 ك.ب | Google Fonts |
| حساب المواقيت | كود محلي | api.aladhan.com |

**الاستثناء الوحيد**: التلاوة الصوتية وصوت الأذان يُبَثّان من الشبكة — ملفات التلاوة
كاملةً تتجاوز 200 ميجابايت فلا تُرفق داخل الـ APK. النص والتفسير والمواقيت تعمل دون
اتصال، وعند انقطاع الشبكة تظهر رسالة واضحة عند محاولة التشغيل الصوتي فقط.

للتحقق: `npm i --no-save playwright && npm run test:offline` — يشغّل التطبيق في
متصفح حقيقي مع حجب كل الشبكة الخارجية.

## هيكل المشروع

```
islamic-app/          ← مصدر تطبيق الويب (هو المنشور على GitHub Pages)
  index.html            هيكل الواجهة والأقسام
  styles.css            التصميم (ثيم داكن أخضر/ذهبي)
  app.js                منطق التطبيق كاملاً
  adhkar-data.js        بيانات الأذكار
  quran-data.js         تحميل نص المصحف والتفسير محلياً
  prayer-times.js       حساب مواقيت الصلاة فلكياً على الجهاز
  data/                 المصحف والتفسير والمدن (مولَّدة بسكربتات scripts/)
  fonts/                الخطوط العربية محلياً بدل Google Fonts
  live-updates.js       التحديثات المباشرة (Capgo) — بلا إعادة بناء APK
  floating-widget.js    الـ SDK الخاص بالزر العائم فوق التطبيقات
www/                  ← نسخة من islamic-app يستخدمها Capacitor لبناء الأندرويد
android/              ← مشروع أندرويد (Capacitor) + البلاجن الأصلي للزر العائم
scripts/               ← مولّدات البيانات (المصحف، التفسير، المدن، الخطوط) + sync-web
tests/offline.mjs      ← اختبار الاستقلال عن الإنترنت في متصفح حقيقي
docs/native-shell.md  ← دليل الغلاف الأصلي: الصلاحيات، التحديث المباشر، الزر العائم
capacitor.config.json ← إعدادات Capacitor (appId: com.noor.islamicapp)
.github/workflows/    ← نشر تلقائي على GitHub Pages عند كل push
```

## التشغيل محلياً

التطبيق يحتاج خادم ملفات ثابتة (لأنه يقرأ بيانات المصحف عبر `fetch`):

```bash
cd islamic-app && python -m http.server 8090
```

ثم افتح <http://localhost:8090>

## بناء تطبيق الأندرويد

الـ APK يُبنى **مرة واحدة فقط**. كل الصلاحيات معلنة مسبقاً في الـ Manifest، وكود
الويب يُحدَّث لاسلكياً بعد ذلك عبر Capgo.

**الأسهل — GitHub Actions يبنيه نيابةً عنك** (بلا Android Studio ولا SDK):
تبويب **Actions** → *بناء تطبيق الأندرويد (APK)* → **Run workflow**، ثم نزّل
الملف من قسم **Artifacts**.

**أو محلياً** (يتطلب Android SDK):

```bash
npm install
npm run build:debug      # = sync:web + cap sync + gradlew assembleDebug
```

### تحديث المستخدمين بعد ذلك (بلا APK جديد)

```bash
npm version patch        # 1.0.0 → 1.0.1
npm run bundle:upload    # يضغط www في Zip ويرفعه لقناة production
```

التفاصيل الكاملة — الصلاحيات، التحديث المباشر، الزر العائم وواجهته البرمجية —
في **[docs/native-shell.md](docs/native-shell.md)**.

### الغلاف الأصلي باختصار

| الميزة | الحالة |
|---|---|
| كل الصلاحيات (كاميرا، ميكروفون، تخزين، موقع، إشعارات، بصمة، بلوتوث، Overlay) | معلنة مسبقاً — تُفعَّل من الويب بلا APK جديد |
| تحديثات الويب المباشرة | `@capgo/capacitor-updater` — يفحص عند كل فتح ويطبّق في الخلفية |
| الزر العائم فوق التطبيقات | بلاجن أصلي مخصص، شكله وسلوكه بالكامل من الجافاسكريبت |
| الكاميرا/الميكروفون (WebRTC) | `getUserMedia()` يعمل مباشرة — Capacitor يترجم طلب الإذن تلقائياً |

## مصادر البيانات

كلها تُحمَّل مرة واحدة وقت التطوير وتُرفق مع التطبيق (انظر `scripts/`):

- نص المصحف — حزمة [quran-db](https://www.npmjs.com/package/quran-db) برسم حفص
- حدود الصفحات والأجزاء والأرباع — حزمة [quran-meta](https://www.npmjs.com/package/quran-meta)
- تفسير الميسر — مستودع [spa5k/tafsir_api](https://github.com/spa5k/tafsir_api)
- إحداثيات المدن — حزمة [all-the-cities](https://www.npmjs.com/package/all-the-cities) (مصدرها GeoNames)
- الخطوط — حزم [Fontsource](https://fontsource.org)
- حساب المواقيت — خوارزمية فلكية محلية (`prayer-times.js`)، مُتحقَّق منها بمطابقة
  مكتبة [adhan](https://www.npmjs.com/package/adhan) في 5 مدن على 3 قارات

المورد الوحيد الذي يُطلب وقت التشغيل: تلاوة الآيات من
[everyayah.com](https://everyayah.com) (مشاري راشد العفاسي، 128kbps).

## ملاحظات

- التطبيق يعمل دون إنترنت في كل شيء عدا التلاوة الصوتية وصوت الأذان.
- ملفات الصوت المحلية (`islamic-app/audio/`, ‏222MB) **غير مرفوعة** في هذا الريبو — التطبيق يجلب التلاوة من everyayah.com مباشرة.
- التاريخ الهجري يُعرض تلقائياً، وآخر موقع/مدينة لمواقيت الصلاة يُحفظ ويُسترجع.

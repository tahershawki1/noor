# نور — تطبيق إسلامي 🌙

تطبيق إسلامي بواجهة عربية كاملة (RTL) يعمل في المتصفح وكتطبيق أندرويد.

## 🌐 افتح التطبيق

**https://tahershawki1.github.io/noor/**

## الأقسام

| القسم | الوصف |
|---|---|
| 📖 **القرآن الكريم** | تصفح 114 سورة بخط المصحف (Amiri Quran)، بحث عن السور، تنقل، وتشغيل تلاوة الآيات صوتياً (مشاري العفاسي). |
| 📿 **الأذكار** | أذكار الصباح والمساء وبعد الصلاة والنوم والاستيقاظ وأدعية جامعة (من حصن المسلم)، مع عدّاد تكرار لكل ذكر وسبحة إلكترونية. |
| 🔖 **الإشارات المرجعية** | احفظ أي آية وارجع إليها لاحقاً. تُحفظ محلياً في `localStorage`. |
| 🕌 **مواقيت الصلاة** | حسب موقعك الجغرافي أو باسم المدينة، مع بطاقة الصلاة القادمة وعدّ تنازلي مباشر، والأذان. |
| 🧠 **الذاكرة** | سجلّ بكل ما أدخلته في التطبيق، مع بحث وتصدير واستيراد ومزامنة اختيارية مع الخادم. |

## 🧠 الذاكرة

كل ما تُدخله في التطبيق يُسجَّل تلقائياً: تغيير الإعدادات، الإشارات المرجعية،
عدّاد السبحة، عمليات البحث، آخر موضع قراءة، مدينة المواقيت… يُحفظ الكل محلياً
(آخر 3000 مدخل)، ويمكن:

- **البحث والترشيح** داخل السجل حسب النوع أو النص.
- **التصدير والاستيراد** كملف JSON — لنقل إعداداتك إلى جهاز آخر.
- **المزامنة مع الخادم** (اختيارية): ارفع مدخلاتك وحالتك، واسترجعها على أي جهاز.

القسم متاح من البلاطة "الذاكرة" في الصفحة الرئيسية أو من الإعدادات.

## 🔄 التحديث التلقائي

عند نشر أي تحديث على `main` يظهر للمستخدم شريط **"يتوفر تحديث جديد"** مباشرة،
ويمكن تفعيل التحديث التلقائي بدون سؤال من قسم الذاكرة.

آلية الاكتشاف بالترتيب:

1. **بثّ حيّ من الباك اند (SSE)** — يعرف الخادم بالـ push خلال ثوانٍ عبر ويب هوك GitHub.
2. **سؤال الباك اند دورياً** عن آخر إصدار.
3. **ملف `version.json`** المنشور مع الموقع — يعمل بدون باك اند إطلاقاً.
4. **واجهة GitHub مباشرة** كخطة أخيرة.

عند كل نشر يكتب سير العمل `version.json` ويختم `index.html` برقم النسخة، ويضيف
`?v=<sha>` لملفات CSS/JS حتى لا يخدم المتصفح نسخة قديمة بعد التحديث.

## هيكل المشروع

```
islamic-app/          ← مصدر تطبيق الويب (هو المنشور على GitHub Pages)
  index.html            هيكل الواجهة والأقسام
  styles.css            التصميم (ثيم داكن أخضر/ذهبي)
  app.js                منطق التطبيق كاملاً
  adhkar-data.js        بيانات الأذكار
  memory.js             ذاكرة المدخلات (تُحمَّل أولاً لتلتقط كل عمليات الحفظ)
  memory-ui.js          واجهة قسم الذاكرة
  updates.js            اكتشاف التحديثات وشريط التنبيه
  version.json          نسخة الإصدار المنشور (تُكتب آلياً عند النشر)
server/               ← الباك اند (Node.js/Express) — الذاكرة ومراقبة GitHub
scripts/              ← أدوات البناء (ختم النسخة، نسخ www)
www/                  ← نسخة من islamic-app يستخدمها Capacitor لبناء الأندرويد
android/              ← مشروع أندرويد (Capacitor)
capacitor.config.json ← إعدادات Capacitor (appId: com.noor.islamicapp)
.github/workflows/    ← نشر تلقائي على GitHub Pages عند كل push
```

## التشغيل محلياً

الواجهة وحدها (خادم ملفات ثابتة):

```bash
cd islamic-app && python -m http.server 8090
```

أو الواجهة + الباك اند معاً من نفس المصدر:

```bash
npm run server:install   # مرة واحدة
npm run server           # http://localhost:8787
```

## الباك اند

يوفّر تخزين الذاكرة ومراقبة تحديثات GitHub. التفاصيل الكاملة (الواجهات،
المتغيرات، الويب هوك، النشر) في [`server/README.md`](server/README.md).

## بناء تطبيق الأندرويد

`www/` هي نسخة من محتوى `islamic-app/` (بدون الصوتيات):

```bash
npm run sync:www         # ينسخ islamic-app/ → www/
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```

# نور — تطبيق إسلامي

تطبيق ويب إسلامي بواجهة عربية كاملة (RTL) يعمل في المتصفح.

## الأقسام

1. **📖 القرآن الكريم** — تصفح 114 سورة بخط المصحف (Amiri Quran)، بحث عن السور، تنقل بين السور. النص من [alquran.cloud](https://alquran.cloud).
2. **📿 الأذكار** — أذكار الصباح والمساء وبعد الصلاة والنوم والاستيقاظ وأدعية جامعة (من حصن المسلم) مع عدّاد تكرار لكل ذكر، وسبحة إلكترونية بعبارات متعددة.
3. **🔖 الإشارات المرجعية** — احفظ أي آية بزر «حفظ»، وارجع إليها من قسم المحفوظات (فتح مع تمييز الآية، أو حذف). تُحفظ في localStorage.
4. **🕌 مواقيت الصلاة** — حسب موقعك الجغرافي أو باسم المدينة، مع بطاقة الصلاة القادمة وعدّ تنازلي مباشر. المواقيت من [Aladhan API](https://aladhan.com/prayer-times-api) (طريقة حساب أم القرى).

## التشغيل

يحتاج فقط لخادم ملفات ثابتة (بسبب طلبات الـ API):

```
cd islamic-app
python -m http.server 8090
```

ثم افتح: http://localhost:8090

## الملفات

- `index.html` — هيكل الواجهة والأقسام الأربعة
- `styles.css` — التصميم (ثيم داكن أخضر/ذهبي)
- `app.js` — منطق التطبيق كاملاً
- `adhkar-data.js` — بيانات الأذكار

## ملاحظات

- يتطلب اتصالاً بالإنترنت لتحميل نص القرآن ومواقيت الصلاة (الأذكار والسبحة تعمل بدون إنترنت بعد أول تحميل).
- التاريخ الهجري يُعرض تلقائياً في أعلى الصفحة.
- آخر موقع/مدينة لمواقيت الصلاة يُحفظ ويُسترجع تلقائياً.
